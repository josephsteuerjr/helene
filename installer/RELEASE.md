# Как выпустить версию Hélène

1. Поднять версию в трёх `Cargo.toml` (`shell`, `setup`, `svc`) — одно число,
   например `0.2.0`. Из `shell/Cargo.toml` её читает окно («О программе»).
2. Собрать всё: интерфейсы (`npm --prefix app run build`, `mobile`, `setup/ui`),
   `cargo build --release --features custom-protocol` в `shell` и `setup`,
   `cargo build --release` в `svc`, затем `python installer/build_dist.py`
   (без `--skip-runtime`, если рантайм менялся). Итог — `installer/build/Helene.zip`.
3. Проверить состав архива: в `tree/` нет `.env`, `private/`, `workspace_*.md`,
   резервных копий; в корне есть ЛИЦЕНЗИЯ.md, ЛИЦЕНЗИИ-ТРЕТЬИХ-СТОРОН.md,
   КАК-УСТРОЕН-HELENE.md, ПЕРВЫЙ-ЗАПУСК.md.
4. Записать изменения в `CHANGELOG.md`. На GitHub: тег `v0.2.0`, релиз с этим
   тегом, к релизу прикрепить `Helene.zip`. В описании релиза первая строка —
   что изменилось: её показывает окно.
5. Адрес для проверки обновлений в настройках:
   `https://api.github.com/repos/<владелец>/<репозиторий>/releases/latest`.
   Окно сравнивает `tag_name` со своей версией, показывает первую строку
   описания и даёт ссылку на `Helene.zip`. Ничего не скачивает и не подменяет:
   пользователь распаковывает архив и запускает установщик поверх, данные
   агента остаются.

Подписи кода нет: SmartScreen при первом запуске просит «Подробнее → Выполнить
в любом случае», об этом сказано в ПЕРВЫЙ-ЗАПУСК.md.
