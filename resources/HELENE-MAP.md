# Как устроена Helene

Карта для агента и для человека, который хочет что-то переписать. Здесь нет
истории и планов, только то, что лежит в папке программы и как это связано.

## Папка программы

| Что | Где | Можно ли переписать |
|---|---|---|
| Оболочка: окно, значок у часов, надзор за процессами, уведомления | `helene.exe` | Скомпилировано из Rust (`shell/` в репозитории Helene). Правится только пересборкой |
| Установщик и снятие | `helene-setup.exe` | Rust (`setup/`), пересборкой |
| Служба Windows | `helene-svc.exe` | Rust (`svc/`), пересборкой |
| Реле подписки ChatGPT | `helene-relay.exe` | Rust, отдельный проект |
| Труба: HTTP и WebSocket, которыми окно и телефон читают состояние и пишут в комнаты | `app/deskapp.py`, `app/deskd/readers.py` | Python, правится на месте, применяется перезапуском |
| Харнесс: рождение, ходы, сердцебиение, доставка слова, Telegram Bot API | `app/localharness/runner.py`, `boot.py`, `transport.py`, `botapi.py` | Python, правится на месте, применяется перезапуском |
| Страница телефона | `app/mobile/` | Собранный TypeScript (`mobile/` в репозитории) |
| Интерфейс окна | `app/static/` | Собранный TypeScript (`app/` в репозитории) |
| Код агента: модель, кадр, память, руки, восприятие | `tree/` | Python, правится на месте; карта файлов в `tree/CODEMAP.md`, контракты в `tree/ARCHITECTURE.md` |
| Данные агента: память, дневник, комнаты, конституция, рабочая папка, вход в ChatGPT | `data/` | Это и есть жизнь агента; не код |
| Встроенный Python со всеми пакетами | `runtime/` | Не трогать |
| Настройки: имена, модель, Telegram, телефон, обновления | `helene.json` | Правится в окне «Настройки» или руками; применяется перезапуском |
| Журнал оболочки | `helene.log` | Читать при сбоях |
| Вывод трубы и харнесса | `data/deskapp.log`, `data/runner.log`, `data/service.log` | Читать при сбоях |

## Как проходит ход

1. Слово приходит в комнату: окно пишет через трубу, Telegram через Bot API,
   телефон через ту же трубу по ключу устройства.
2. Руннер (`app/localharness/runner.py`) замечает новое, собирает кадр силами
   `tree/agent.py` и зовёт модель по адресу из `helene.json`.
3. Модель думает и действует руками столько поворотов, сколько нужно. Каждый
   поворот записан в `data/memory/runs/`.
4. Слово наружу уходит рукой `reply` с распиской в архив комнаты
   (`data/memory/groups/<комната>.jsonl`). Оболочка читает архив окна и, если
   окно не перед глазами, показывает уведомление.
5. Состояние для шапки окна собирает `app/deskd/readers.py`: не запущен, модель
   не настроена, думает, ждёт, на связи.

## Что запускает что

- Окно `helene.exe` читает `helene.json` и поднимает детей: реле (если подписка
  ChatGPT), трубу `deskapp.py` и руннер. Упавший ребёнок поднимается снова с
  паузой; после шести падений за десять минут оболочка делает паузу и говорит
  об этом уведомлением.
- Если стоит служба, детей держит `helene-svc.exe`, а окно только подключается
  к порту трубы.
- Перезапуск из настроек убивает детей и поднимает всё заново уже с новым кодом
  и новыми настройками.

## Как переписывать себя

- Всё на Python рядом с программой правится на месте. После правки нужен
  перезапуск: кнопка «Перезапустить» в настройках или перезапуск службы.
- Перед правкой кода агента читать `tree/CODEMAP.md`: там роль каждого файла.
  Ломающая правка не убивает программу насовсем: оболочка поднимет руннер
  снова, а причина будет в `data/runner.log`.
- Rust-части и интерфейсы на TypeScript правятся только из исходников
  репозитория Helene и пересобираются. Для этого нужны Rust и Node на машине.
- Изменения в `helene.json` без окна: файл обычный JSON, но перезапуск всё
  равно нужен.
